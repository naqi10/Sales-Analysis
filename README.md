# Sales-Analysis
This project analyzes sales data to uncover trends, insights, and patterns that can guide business decisions. It includes data preprocessing, exploratory data analysis (EDA), and insightful visualizations using Python and popular data science libraries.
🧠 Objectives
Combine monthly sales data into a single dataset

Clean and preprocess the dataset

Perform exploratory data analysis

Identify key trends such as:

Best month for sales

Most sold products

City-wise performance

Hourly purchase behavior

 Technologies Used
Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook

 Key Insights
Some of the insights extracted from this analysis include:

Peak Sales Month: Identified the month with the highest sales volume.

Top Performing Cities: Determined which cities generate the most revenue.

Product Popularity: Found the most frequently sold items and recommended stock optimization.

Sales by Hour: Suggested optimal ad display times based on hourly purchase data.

 Sample Visualizations
